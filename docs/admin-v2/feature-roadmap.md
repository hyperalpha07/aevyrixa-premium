# Admin V2 Feature Roadmap

## Phase 1: Foundation

- Protected `/admin-v2` route group.
- Materio-inspired shell with sidebar, topbar, drawer navigation, scoped MUI theme, command palette, notification drawer, profile menu, reusable components.
- Dashboard with real available data and no fake business records.
- Route-safe placeholders for planned modules.

## Phase 2: Commerce Workflows

- Orders table with filters, status updates, courier fields, export permissions, and detail view.
- Product list, create/edit product forms, media linkage, and product status workflows.
- Categories, inventory, reviews, customers, returns, and discounts.

## Phase 3: Communication And Operations

- Support inbox and chat workflows.
- Email and notification templates.
- Media manager, calendar, kanban, courier integrations, and automation.

## Phase 4: Team And Governance

- Staff management.
- Role editor.
- Permission matrix.
- Audit logs.
- Approval queues.

## Phase 5: Analytics And Finance

- Analytics backed by real orders/customers/products/reviews.
- Reports.
- Invoices, transactions, expenses, refunds, tax, and billing only after real data sources are defined.

## Phase 6: Hardening

- Accessibility pass.
- Responsive QA.
- API error states.
- Audit logging for Admin V2 mutations.
- Optional chart dependency review.
- Side-by-side migration plan for retiring old `/admin` only after approval.
